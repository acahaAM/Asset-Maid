# Asset Maid

RisuAI Plugin API v3용 Asset Maid의 정식 배포 파일입니다. 이 저장소에는 빌드된 JavaScript와 설치 안내, SHA-256 체크섬만 보관합니다.

## 설치

1. [AssetMaid.js 다운로드](https://raw.githubusercontent.com/acahaAM/Asset-Maid/main/AssetMaid.js)를 파일로 저장합니다.
2. RisuAI 설정의 플러그인 화면에서 해당 JS 파일을 가져옵니다.
3. 기존 Asset Maid가 있으면 교체 확인을 승인합니다. 기존 플러그인을 미리 삭제하거나 저장 데이터를 초기화하지 않습니다.

GitHub 정식 배포·원격 업데이트는 0.9.8부터 시작합니다. 기존 설치본은 0.9.8 정식 파일을 한 번 직접 설치하세요. 0.9.72·0.9.73·0.9.74는 출시 전 시험 버전이며, 0.9.8보다 숫자 비교상 높아 자동 업데이트로 전환되지 않습니다.

## 업데이트

새 버전이 게시되면 RisuAI 플러그인 설정에서 업데이트가 표시됩니다. 업데이트 버튼을 누르고 설치를 승인하면 새 JS를 다운로드하여 같은 이름의 플러그인을 교체합니다. 무인 자동 설치 방식은 아닙니다.

개발 Loader·개발 번들은 이 정식 업데이트 경로를 사용하지 않습니다. 설치 파일 내부의 `//@version`으로 제품 버전을 확인할 수 있습니다. 이전 출시는 해당 `v<버전>` Git 태그에서 확인할 수 있습니다.

`SHA256SUMS.txt`는 내려받은 파일을 수동으로 대조하는 자료입니다. RisuAI가 이 체크섬 파일을 자동 검증하는 것은 아닙니다.
