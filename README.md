# Asset Maid

RisuAI 채팅에 이미지 생성과 에셋 관리를 더하는 플러그인입니다.

대화에 맞는 이미지를 생성하고, 캐릭터의 외형·의상·참조 이미지와 프롬프트를 관리할 수 있습니다. 생성한 이미지는 History에서 확인하고 다시 생성하거나 수정할 수 있습니다.

**[최신 버전 다운로드](https://raw.githubusercontent.com/acahaAM/Asset-Maid/main/AssetMaid.js)** · **[주요 업데이트 내역](https://github.com/acahaAM/Asset-Maid/releases)**

## 설치

1. 위 다운로드 링크에서 **AssetMaid.js** 파일을 저장합니다.
2. RisuAI **설정 → 플러그인**에서 내려받은 JS 파일을 가져옵니다.
3. 기존 Asset Maid가 있다면 교체를 승인합니다.

기존 플러그인을 미리 삭제하거나 저장 데이터를 초기화할 필요는 없습니다.

## 업데이트

RisuAI 플러그인 설정에 업데이트가 표시되면 버튼을 누르고 설치를 승인하세요.

업데이트가 표시되지 않으면 위 다운로드 링크에서 최신 파일을 받아 같은 방법으로 설치할 수 있습니다.

주요 업데이트는 [Releases](https://github.com/acahaAM/Asset-Maid/releases)에 변경사항과 설치 파일을 함께 보관합니다. 소규모 수정은 원격 업데이트로 제공하므로, 최신 패치가 포함된 파일은 위 **최신 버전 다운로드** 링크를 이용하세요.
